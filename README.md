# Flask Expense Tracker

A simple and clean Expense Tracker Web Application built using Flask and SQLite.

## Features

* Add Expense
* Delete Expense
* Total Expense Calculation
* Bootstrap Styled UI
* Data stored using SQLite

## Tech Stack

* Python
* Flask
* SQLite
* HTML
* Bootstrap

## How to Run

1. Install Flask
2. Run `app.py`
3. Open browser at `http://127.0.0.1:5000`

Database file will be automatically created when the app runs.
